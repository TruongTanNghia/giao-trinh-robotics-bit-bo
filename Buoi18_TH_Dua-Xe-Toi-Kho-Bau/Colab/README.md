## Chương trình mẫu (mô tả khối)

```
khi bắt đầu
  tiến 2 giây
  rẽ phải 0,5 giây
  tiến 1 giây
  bật đèn
  phát tiếng bíp
```

Tên khối thay theo phần mềm lập trình khối của trường. Lưu file dự án đã làm xong vào đây.
